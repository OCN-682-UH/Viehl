Now that we can see what we’re working with, let’s say we want to look at how bill geometry differs across penguin species and islands. To do this, let’s begin by making a basic plot.

Basic plot scripting

Click on “Show code” below to see a quick script to make a simple plot. This will give us a very basic view of all the bill length and bill depth data by species.

Show code 
# First, pipe penguins into the plotting function
penguins |> 
  
  # The ggplot function makes the base plot
  ggplot(mapping = aes(x = bill_length_mm,    # sets the x axis
                       y = bill_depth_mm,     # sets the y axis
                       color = species)) +    # colors the data by species
  geom_point()      # this is what actually puts the points on the plot.

This is great, but it would be even better if we could see the differences between each island.

Let’s facet wrap that to see the difference between islands

Click “Show code” to see the facet_wrap addition.

Show code 
penguins |> 
  ggplot(mapping = aes(x = bill_length_mm,
                       y = bill_depth_mm,
                       color = species)) +
  geom_point()+
  facet_wrap(~island, scales = "free")  # facet_wrap allows us to view by
                                        # island, and the scales = free
                                        # makes each graph have its own scale.

Nice! However, in Figure 2, the labels are not great. There is no title, and the island names have no context. We can fix them!

Let’s add some better labels

Click “Show code” below to see how labels are added and modified.

Show code 
penguins |> 
  ggplot(mapping = aes(x = bill_length_mm,
                       y = bill_depth_mm,
                       color = species)) +
  geom_point()+
  facet_wrap(~island, scales = "free")+
  labs(title = "Bill Geometry of Palmer Archipelago Penguins", # sets the title
       subtitle = "On the Islands of Biscoe, Dream, and Torgersen", # subtitle
       x = "Bill Length (mm)",  # X axis label
       y = "Bill Depth (mm)",   # Y axis label
       color = "Species")+      # labels the legend
  theme(plot.title = element_text(face = "bold"))   # makes the plot title bold

Great! We can clearly see in Figure 3 the beak geometry patterns across the islands and species.

Changing the theme

What if you’d like to change the style of the plot to something a little more interesting?

Click “Show code” below to see how you can do this.

Show code 
penguins |> 
  ggplot(mapping = aes(x = bill_length_mm,
                       y = bill_depth_mm,
                       color = species)) +
  geom_point(shape = 18, size = 3, alpha = 0.7)+   # Change the points
  facet_wrap(~island, scales = "free")+
  labs(title = "Bill Geometry of Palmer Archipelago Penguins",
       subtitle = "On the Islands of Biscoe, Dream, and Torgersen",
       x = "Bill Length (mm)",
       y = "Bill Depth (mm)",
       color = "Species")+
  theme_minimal()+                  # theme_minimal() sets the overall theme
  scale_color_manual(values = c("#a31621",
                                "#fed766",    # give it a nice color scheme
                                "#f77f00"))+
  theme(plot.title = element_text(face = "bold"))
